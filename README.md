#Shop quần áo
Dự án này là trang web bán quần áo dành cho các doanh nghiệp, các chủ cửa hàng thời trang đăng bán các sản phẩm của mình.

##Tính năng chính
-Thêm vào giỏ hàng và thanh toán
-Tạo tài khoản và đăng nhập bằng email hoặc tài khoản google

##Yêu cầu
Cài đặt các thư viện sau:
pip install django-allauth
pip install "django-allauth[socialaccount]"      
pip install Pillow 
pip install django
Lệnh chạy chương trình:
py .\manage.py runserver
